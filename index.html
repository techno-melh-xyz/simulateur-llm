À retenir

Les paramètres du modèle ne changent pas pendant l’utilisation. Le préentraînement et le post-entraînement ont été effectués auparavant. En mode distant les calculs sont réalisés chez un fournisseur d’inférence. En mode local, le GPU (WebGPU) réalise les calculs dans le navigateur ; les fichiers du modèle sont téléchargés depuis Hugging Face et peuvent être mis en cache.

Ces modèles peuvent générer des erreurs ou des contenus inadaptés. Utilisation pédagogique encadrée ; ne saisissez pas de données personnelles.
